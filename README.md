## Featured Work

### [llm-requirements-traceability](https://github.com/ijaazm10/llm-requirements-traceability) · master's thesis

An end-to-end LLM evaluation pipeline for cross-level requirements traceability: retrieval, embeddings, a frozen BERT classifier, open-weight and cloud LLMs, FAISS RAG, BM25 hybrid retrieval, and LoRA/QLoRA fine-tuning. Tested on a controlled 42,012-pair hard-negative benchmark from eight open-source projects and evaluated on accuracy, reliability, latency, and cost, with significance testing and bootstrap confidence intervals.
